## 🌟 Overview

**Ultimate Chemistry Simulator** is an interactive 3D science sandbox built from first principles in **Unreal Engine 5**. It bridges the gap between dry 2D chemistry textbooks and video game immersion, featuring real-time **VSEPR 3D molecular auto-relaxation**, an embedded **offline neural reaction predictor (ChemAI)**, and neural voice synthesis.

Built for students, chemistry teachers, indie researchers, and science geeks.

---

## ⚡ Core Features

- 🔬 **Real-Time 3D VSEPR Auto-Relaxation**: Build molecules dynamically in 3D space with continuous electro-repulsion force physics.
- 🧠 **Offline Neural Reaction Predictor (ChemAI)**: Predict complex reaction pathways and products completely locally without cloud API keys or internet connection.
- 🗣️ **Neural Voice Synthesis**: In-simulation voice assistant providing real-time feedback and guidance.
- 📊 **Interactive Periodic Table**: Deep exploration of elemental properties, valencies, and electronegativity.
- 🎮 **Gamified Chemistry Hub**: Minigames and challenge puzzles designed to test reaction kinetics and molecular geometry.
